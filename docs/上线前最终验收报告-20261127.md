## 本轮发现与修复

### 1. 写作者更名未同步当前写作安排

触发：修改写作者姓名后，论文主档姓名更新，但当前写作安排仍存旧名；后续付款会从安排中取得旧姓名。

修复：`src/WriterService.java` 在更新关联论文时同步刷新当前写作安排，并更新论文版本。历史写作安排、既有付款及其经手/收款人记录保留原内容。

验证：新增测试覆盖更名前付款、更名、当前安排、新付款、备份恢复与重启，以及换人后再修改旧写作者姓名。文件存储、MySQL 和本地真实接口检查通过。

### 2. 跨账号恢复包含跟进事项的备份失败

触发：源账号与目标账号在同一 MySQL 库，恢复时论文等实体重新分配编号，但跟进事项及历史编号没有重新分配，导致主键冲突并返回 HTTP 500。

修复：`src/MysqlStore.java` 在跨账号导入时初始化兼容旧跟进数据，统一重映射跟进事项编号、处理历史编号及历史中的事项引用。

验证：新增 MySQL 测试覆盖普通加密备份、完整 ZIP、事项状态与历史关联、源账号不变、附件下载和重启持久化。本地 120 篇完整备份跨账号导入、逐文件校验及后续清理通过。
